## Jam rules that always apply

The SessionStart status shows the current phase. Read the digest only for a specific question about the rules: `{{harness_path}}/knowledge/contest/rules-digest.md`.

- Before the jam starts: tools, configuration, scripts and docs only. No gameplay, levels or art.
- Never rewrite shared history. Epic may request the version control history.
- A person submits the entry on itch.io. Agents prepare the package and the checklist only.
- Every sourced asset goes in the ledger with its license. Sourced assets are not scored, while AI-generated and original work is judged.
- The game must run without extra software. No LLM calls or API keys inside builds.
- Content stays Teen-appropriate and free of third-party logos.
